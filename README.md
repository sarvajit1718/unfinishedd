# CutWise

Agentic Post-Production Director

## Problem

Independent filmmakers lack access to audience intelligence when editing trailers.

## Solution

CutWise uses Gemini and Google Cloud to analyze media and an agentic Grafana MCP integration to understand audience telemetry and recommend creative edits.

## Tech Stack

- Gemini
- Google ADK
- Google Cloud
- Grafana Cloud MCP
- Next.js
